Fair questions, straight answers.

Is the mascot above a video?

No — it is the real viewer running in this page, in 3D, answering your clicks. The faces below are real footage of that same viewer, both characters, and the only proper video is the twenty-four second film.

Do I have to draw anything?

No. Start from a sentence, an image you already have, or a MascotForge export. The skill builds the character, the poses and the motion.

What does it cost?

Nothing. MIT, both the skill and the package — read it, change it, ship it.

How do I know it actually works?

Every run ends with a check: the character is rendered, the five moods are measured against the pose table, and the whole thing is verified before it is handed back. If a number is off, the run says so.

What is the mascot on this page?

Two of them. Axo — a demo character built in code with the skill itself — and Nicklas, a sculpt exported straight out of the studio. Every loop and frame on this page comes from those builds; your mascot will be yours.
